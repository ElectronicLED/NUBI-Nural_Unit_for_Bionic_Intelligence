Default settings test: LAnkle_pitch joint
  • Frequency: 1 Hz
  • Amplitude: 45 degrees
  • Duration: 3 seconds
  • Sampling: 50 Hz (matches real robot)
  
What happens:
  1. Generates 151 sine wave samples
  2. Sends to physical robot (if ROS available)
  3. Records feedback (if available)

  5. Generates PNG plot with 3 overlayed responses
  6. Saves data for later analysis


🔄 REPLAY MODE
==============

Run simulation without re-testing physical robot:

  python3 sim_to_real_bridge.py replay

Benefits:
  ✓ Fast iteration (no ROS overhead)
  ✓ Try different gravity settings
  ✓ Adjust visualization without hardware
  ✓ Compare multiple simulation runs


⚡ COMMON CUSTOMIZATIONS
========================

Change joint:
  "target_joint_idx": 1,  # 0-11

Change frequency:
  "sine_frequency_hz": 0.5,  # or 2.0, 3.0, etc.

Change amplitude:
  "sine_amplitude_deg": 30.0,  # 10-90 degrees

Skip physical robot:
  "use_ros": False,  # Simulation only

Add gravity:
  "sim_gravity": (0.0, 0.0, -9.81),  # Realistic physics
