# Key Features of Project N.U.B.I.

 A fully integrated, 20-Degree-of-Freedom (DoF) bipedal humanoid robot designed to operate autonomously in unstructured, human-centric environments. Below is a detailed summary of its primary engineering features across locomotion, hardware, perception, manipulation, human-robot interaction, and software architecture.
</p>
---

## 1. Advanced Locomotion & Balance


* **Reinforcement Learning Policy:** Employs a neural network trained with Proximal Policy Optimization (PPO) across thousands of parallel GPU simulation environments to discover adaptive walking gaits.


* **Sim-to-Real Actuator Modeling:** Incorporates a custom Herkulex servo dynamic model (with trapezoidal velocity profiling) into simulation to bridge the gap between virtual training and physical hardware deployment.

## 2. Embedded Hardware & Power Architecture

* **STM32 Processing Core:** Powered by a 32-bit ARM Cortex-M4 STM32F401RC ("Black Pill") microcontroller operating at 84 MHz with a hardware Floating Point Unit (FPU) for real-time kinematics calculations.


* **Smart Serial Servo Bus:** Actuated by multi-drop Herkulex DRS-0101 smart serial servos communicating over dual, parallel TTL UART channels.


* **Sensory Balance Feedback:** Integrates an MPU-6050 6-axis Inertial Measurement Unit (IMU) with an on-chip Digital Motion Processor (DMP) for real-time trunk orientation tracking and fall detection.


* **Regenerative Power Management:** Direct-fed by a 7.4 V lithium-ion battery pack capable of absorbing back-EMF voltage spikes generated by motor deceleration.

## 3. Vision, Perception & Navigation

* **Spatial Depth Sensing:** Equipped with a head-mounted OAK-D Lite stereo camera that outputs synchronized RGB video, stereo disparity depth maps, and IMU data.


* **Visual-Inertial SLAM:** Employs RTAB-Map graph-based SLAM to generate dense 3D point-cloud maps and 2D occupancy grids while performing loop closure optimization.


* **Semantic Mapping Pipeline:** Integrates YOLO object detection with 3D point-cloud ray-casting to transform local camera coordinates into globally anchored 3D object targets.


* **Autonomous Navigation:** Utilizes the ROS 2 Nav2 framework featuring $A^*$ global path planning and dynamic costmap inflation to plan collision-free routes.



---

## 4. Manipulation & Kinematics

* **Dual 3-DoF Manipulators:** Features left and right articulated arms capable of independent end-effector positioning in Cartesian space.


* **Underactuated compliant grippers:** Features a compliant 3 finger gripper capable of adapting to the object's shape.


* **MoveIt 2 Integration:** Configured with custom Tool Center Point (TCP) frames, velocity scaling, and automated self-collision matrix optimization.


* **Interactive Workspace Visualizer:** Features a web-based 3D workspace analysis tool (built with Dash/Plotly) for sampling reachability and executing point-and-click pick-and-place routines.

## 5. Spoken Dialogue & Human-Robot Interaction (HRI)

* **Always-On Wake Word Detection:** Operates offline using OpenWakeWord to detect the trigger phrase *"Hey Nubi"*.


* **Offline Speech-to-Text:** Uses Faster-Whisper (`tiny.en` model with 8-bit integer quantization) for real-time speech transcription on CPU.


* **Cognitive Reasoning Engine:** Connects to the Groq Cloud API utilizing the Llama-3.1-8b model combined with keyword-based context retrieval from an onboard memory database.


* **Offline Text-to-Speech:** Generates natural voice responses locally using the Piper neural speech synthesis engine.



---

## 6. Software Middleware & Digital Twin

* **ROS 2 Ecosystem:** Built on a ROS 2 middleware layer using Data Distribution Service (DDS) UDP multicast for decentralized node discovery.


* **Micro-ROS Integration:** Binds bare-metal STM32 microcontroller firmware directly into the ROS 2 network as a native node.
  

* **Control GUI:** Includes a desktop operator dashboard developed in PyQt6 for manual joint tuning, live system diagnostics, and kinesthetic motion playback.
